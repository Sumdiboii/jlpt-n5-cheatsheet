## 🎌 Overview

I had these study sheets sitting on my drive for a while. They helped me a lot when going through Minna no Nihongo, so here they are. Use them for your own prep or reference.

* 📜 **Vocab & Grammar**: Particle usage, basic sentence patterns, and vocabulary for each lesson.
* 🍱 **50 Practice Sentences**: Example sentences for every lesson so you can see the grammar in context.
* 🎴 **2 Files Per Lesson**: Grammar notes and reading practice are split into separate files to keep things clean.
* 🍵 **No Filler**: Straight to the point and easy to review.
